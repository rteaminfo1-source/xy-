# Хранитель малой родины — как запустить (C#)

Идея и описание проекта — в файле **[ИДЕЯ.md](ИДЕЯ.md)**.

## Что нужно

- **.NET 8 SDK** — https://dotnet.microsoft.com/download/dotnet/8.0
- Windows 10/11, Linux или macOS. Лучше всего выглядит в **Windows Terminal** (в Windows 11 он открывается по умолчанию).

## Запуск

- **Windows:** дважды щёлкните `запуск.bat`
- **Visual Studio:** откройте `Hranitel.sln` и нажмите **F5**
- **Командная строка:**
  ```bash
  dotnet run -c Release
  ```

> Окно консоли должно быть не меньше 100×30 символов. Если картинка «поехала» — разверните окно на весь экран.

## Управление

| Клавиша | Действие |
|---|---|
| **↑ ↓** | выбор пункта |
| **1 / 2 / 3** | быстрый выбор решения |
| **Enter** | подтвердить, дальше |
| **← →** | листать залы музея |
| **Пробел** | отметить пункт в паспорте |
| **S** | сохранить летопись / паспорт в HTML (откроется в браузере) |
| **Esc** | назад, в меню |

HTML-файлы сохраняются в папку `Летописи` рядом с программой.

## Структура

```
Program.cs     главное меню с анимированной панорамой «машина времени»
Game.cs        игра: эпохи, выборы, итог
Story.cs       сюжет: 9 эпох × 3 решения, 5 финалов
Scene.cs       пиксельная панорама села для любого года и набора технологий
Pixels.cs      пиксельный холст (▀ = 2 пикселя), пиксельный шрифт 5×7, «объектив» эпохи
Term.cs        экранный буфер, 24-битный цвет, рамки, полосы, ввод с клавиатуры
Passport.cs    «Цифровой паспорт малой родины»: анкета, индекс, советы
Museum.cs      «Музей технологий»: 13 залов
Report.cs      HTML-отчёты: летопись и паспорт
screenshots/   скриншоты
```
