# Нейролетопись малой родины — как запустить (Python)

Идея и описание проекта — в файле **[ИДЕЯ.md](ИДЕЯ.md)**.

## Что нужно

Только **Python 3.8 или новее** (https://www.python.org/downloads/ — при установке отметьте «Add Python to PATH»).
Сторонние библиотеки не нужны: интерфейс на Tkinter, нейросеть написана с нуля.

## Запуск

- **Windows:** дважды щёлкните `запуск.bat`
- **Любая система:**
  ```bash
  python main.py
  ```

> Linux: если нет Tkinter — `sudo apt install python3-tk`.

## Управление

| Клавиша / действие | Что происходит |
|---|---|
| **1 / 2 / 3 / 4** | вкладки: Летопись · Нейросеть · Прогноз 2050 · О проекте |
| **↑ / ↓** или клик по карточке | выбор села |
| **R** или «обучить заново» | обучить нейросеть с нуля (новые случайные веса) |
| Ползунки на вкладке «Прогноз» | уровень каждой технологии к 2035 году |
| Кнопки «Как сейчас / Без технологий / Рывок / Гармония» | готовые сценарии |

## Свои данные

Откройте `data/district.csv` в Excel или любом редакторе. Колонки:

```
village, year, population, youth, internet, digital, remote, smart, roads, heritage
```

`youth` и технологии — доли от 0 до 1. Добавьте строки своего села (минимум несколько лет подряд), сохраните в UTF‑8 и перезапустите программу.
Если удалить файл, он будет создан заново генератором (`neuroletopis/data.py`).
