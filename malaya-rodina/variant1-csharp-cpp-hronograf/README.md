# Хронограф малой родины — как запустить (C# + C++)

Идея и описание проекта — в файле **[ИДЕЯ.md](ИДЕЯ.md)**.

## Что нужно

- Windows 10/11 (64‑бит).
- **Visual Studio 2022** с нагрузками «Разработка классических приложений .NET» и «Разработка классических приложений на C++»
  — *или* только **.NET 8 SDK** (https://dotnet.microsoft.com/download/dotnet/8.0).

## Способ 1 — Visual Studio (рекомендуется)

1. Откройте `Hronograf.sln`.
2. Вверху выберите конфигурацию **Release | x64**.
3. Нажмите **F5**. Visual Studio сама соберёт C++ движок (`Engine`) и C# приложение (`Hronograf`).

## Способ 2 — одной командой

Дважды щёлкните `build.bat`. Скрипт найдёт компилятор C++ (Visual Studio или MinGW), соберёт движок и запустит приложение.
Если компилятора C++ нет — будет использован готовый движок из `Engine/prebuilt/win-x64/`.

## Способ 3 — только .NET SDK

```bat
cd App
dotnet run -c Release
```

## Управление

| Клавиша / действие | Что происходит |
|---|---|
| **Пробел** | пауза / воспроизведение |
| **← →** | год назад / вперёд |
| **Home / End** | 1900 / 2060 |
| **1 / 2 / 3** | сценарий: Инерция / Рывок / Гармония |
| **N** или кнопка ☾ | день / ночь |
| Шкала внизу | перетаскивайте ползунок, наводите на ромбики — события |
| Поле «Малая родина» + Enter | создать карту для своего села |

### Параметры запуска (удобно на защите)

```bat
Hronograf.exe --name "Сосновка" --year 1945 --night --pause
Hronograf.exe --today           :: сразу к развилке «сегодня» и выбору сценария
Hronograf.exe --scenario 1      :: 1 — Инерция, 2 — Рывок, 3 — Гармония
```

## Структура

```
Hronograf.sln            решение Visual Studio (C# + C++)
build.bat                сборка и запуск одной командой
App/                     C# — интерфейс (WinForms, .NET 8)
  MainForm.cs            окно, анимация, клавиши
  MapView.cs             «видоискатель»: кадр → объектив C++ → интерфейс камеры эпохи
  SceneRenderer.cs       рисование села: рельеф, поля, лес, дома, свет окон
  SidePanel.cs           показатели, технологии, график сценариев
  TimelineBar.cs         шкала времени с эпохами и событиями
  HeaderBar.cs           шапка, выбор сценария
  Chronicle.cs           летопись: данные трёх сценариев и тексты событий
  Native.cs              P/Invoke-мост к C++
Engine/                  C++17 — движок
  engine.h / engine.cpp  генерация карты, симуляция 1900–2060, обработка кадра
  Engine.vcxproj         проект Visual Studio
  CMakeLists.txt         сборка через CMake
  prebuilt/win-x64/      готовая DLL (на случай, если нет компилятора C++)
screenshots/             скриншоты всех эпох
```

## Если что-то не так

- **«Не найден C++ движок»** — соберите решение (Сборка → Собрать решение) или запустите `build.bat`.
- **BadImageFormatException** — движок и приложение должны быть 64‑битными (конфигурация x64).
- Скриншоты в папке `screenshots/` сняты в эмуляторе; в Windows шрифты (Segoe UI, Bahnschrift) выглядят ещё лучше.
