# «Судьба Республики Беларусь» на iPhone и iPad

Файл приложения — `BelarusTech.ipa` (в папке игры). Это настоящее приложение, а не сайт.
Его собирает GitHub на компьютере Mac (`.github/workflows/ios.yml`) из того же кода, что и `BelarusTech.exe`.

## Как установить

Apple разрешает ставить приложения не из App Store только через специальные программы.
Бесплатно это делают **SideStore** или **AltStore**: они подписывают приложение вашим Apple ID.

1. Один раз установите SideStore (sidestore.io) или AltStore (altstore.io) на iPhone по инструкции на их сайте.
   Для первой установки нужен компьютер (подойдёт Windows) и обычный Apple ID.
2. Скачайте `BelarusTech.ipa` на iPhone (например, сохраните из Telegram или почты в приложение «Файлы»).
3. Откройте SideStore/AltStore → «Мои приложения» → «+» → выберите `BelarusTech.ipa` в «Файлах».
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID
   (и включить «Режим разработчика» в Настройки → Конфиденциальность, если iPhone попросит).
5. Значок «Судьба Беларуси» появится на экране «Домой».

С бесплатным Apple ID приложение нужно продлевать раз в 7 дней: SideStore/AltStore → «Обновить» (одна кнопка).

## Управление

| На компьютере | На iPhone |
|---|---|
| щелчок | касание |
| правая кнопка (приказ армии) | долгое нажатие |
| колесо в списках | палец вверх-вниз |
| сдвиг карты (правая кнопка) | палец по карте |
| колесо над картой | щипок двумя пальцами |
| поворот и наклон карты (левая кнопка) | два пальца: повернуть или двигать вверх-вниз |

Сохранение — само, когда приложение сворачивается. Игра работает без интернета.

## Для разработчика

- `port/ios/build.sh` — собрать `.ipa` на Mac (Xcode); `port/ios/shots.sh` — снимки в симуляторе.
- `port/linux/run.sh СЦЕНА out.png [W H МАСШТАБ]` — та же сборка без Windows на Linux (шрифты FreeType),
  кадр сцены разработчика в картинку: проверка без Mac.
- Общий код: `src/win32_shim.h` и `src/plat_gdi.c` — подмножество Win32/GDI, которым пользуется игра;
  `src/plat_host.h` — события окна и что даёт приложение-хозяин.
